# 專案規則

## 技術限制

- 僅使用純 HTML、CSS、JavaScript，不引入任何框架或套件
- 不使用 Node.js、Vite、React 或任何前端框架
- 不建立後端服務，不連接資料庫
- 不使用 npm / yarn，不需要 package.json
- 圖表若有需要，以原生 Canvas API 或純 CSS 實作

## 檔案結構

- 所有網站檔案（HTML、CSS、JS）一律放在 `docs/` 資料夾內
- 入口點為 `docs/index.html`

## 資料

- 所有資料使用模擬資料（mock data），以 JavaScript 物件或陣列直接定義在程式碼中
- 不串接任何外部 API 或即時資料來源

## 語言

- 介面文字、程式碼註解、文件一律使用繁體中文

## 設計原則

- 保持簡潔，避免過度開發
- 功能以「夠用、能展示」為目標，不追求完整產品功能
- 視覺風格以清晰易讀為主，適合簡報展示
